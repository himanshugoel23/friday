9. Browser-agent headline scores overstate reliability (OSWorld-Verified 83.5% vs OSWorld 2.0 20.6% for one model, **unverified**). Friday's edge is recovery on Indian sites, not the model.
10. DPDP consent-manager milestone is **2026-11-13**; main DPDP duties start **2027-05-13**; IT Rules (2026-02-20) label synthetic audio. Plan, do not panic.

## Regulation and platform risk, India (brief)
- **TRAI Third Amendment to TCCCPR, notified 2026-09-18 (reported)**: AI voice agents count as automated (A2P) calls to be declared; undeclared traffic can be treated as spam, with a reported termination charge up to Rs 0.05 per minute; operators must use AI/ML spam detection (reported: three complaints plus an AI flag can trigger action; sources differ). A vendor blog says AI voices must be disclosed at call start: **unverified, not in news reports**. Sources: https://www.deccanchronicle.com/amp/business/trai-tightens-anti-spam-rules-brings-ai-based-detection-automated-calls-under-framework-1988473 ; https://telecomlead.com/telecom-services/trai-tightens-spam-call-rules-with-ai-ml-detection-%E2%82%B90-05-a2p-charge-and-faster-enforcement-127804 ; https://www.ringg.ai/voice-ai-compliance-india (vendor). Official text not read.
- **DPDP Rules**: published 2025-11-13; consent-manager framework due 2026-11-13; most duties (rules 3, 5-16, 22, 23) from 2027-05-13. https://www.taxmann.com/post/blog/analysis-indias-dpdp-act-and-rules/ ; https://www.mondaq.com/india/privacy-protection/1708830/dpdp-act-compliance-mandate (law-firm summaries). Voice recordings of vendors and users will count as personal data; delete/export tools (already planned) are the cheap prep.
- **IT Rules amendment on synthetic content**: in force 2026-02-20; covers audio that appears real; labelling duties fall on platforms; a 2026-04-21 draft on persistent labels is not confirmed as final. https://www.hoganlovells.com/en/publications/india-introduces-mandatory-labelling-for-ai-and-3hour-takedown-for-illegal-content (2026). Friday does not clone voices; a clearly labelled synthetic voice is consistent with this.
- **WhatsApp**: AI-provider rule (row 18), calling permission rules (row 16), possible billable service messages (row 17).

## (c) TOP 7 recommendations (ranked by user-experience impact and moat)
1. **Build a Hinglish phone-call test bench and bake off the voice stack.** Why first: every other voice choice (Bulbul V4 Flash, Saaras v4, Gemini Live, gpt-realtime-2, IndicConformer) is a claim until measured on 8 kHz Hinglish with names, numbers, noise. The labelled call set and judge prompts are the part a copycat cannot download.
   First step: record 50 scripted vendor calls (price, slot, "call back", refusal) from the pilot SIM to the founder's allow-listed number only; run each stack on them offline. Measure: word error rate on names and numbers, time to first audio, barge-in success, task-success per call, cost per minute.
2. **Compliance pack before the first tester (blocker, in parallel).** Read the notified TRAI Third Amendment text; get Vobiz to confirm A2P/CLI declaration and whether Friday's user-requested vendor calls need it; fix the AI-disclosure opening line; map DPDP duties and the delete-everything tool. Measure: vendor answer rate vs a control (calls from a declared vs undeclared line), spam-flag reports, zero un-disclosed calls.
3. **Add "call Friday on WhatsApp" using the Business Calling API** for user-to-Friday voice, plus permission-based callbacks. Impact: no app, no minutes bill for the user leg, fits "voice-first iPhone" decisions. First step: spike a single inbound WhatsApp call to the existing voice pipeline on the test number; read Meta's limits directly (third-party limits conflict). Measure: setup success, audio quality vs PSTN, cost per minute, share of users who choose it.
4. **Distil the listener and speech clean-up into a small tuned model on Friday's own labelled data.** Closed label set (quote given, price, slot, callback time, refused, asks a question) with a confidence threshold, ask the user when unsure. Moat: data compounds with use. First step: export 300 labelled vendor sentences and run an A/B against the current LLM prompt. Measure: label accuracy, latency, cost per call, and rate of "asked the user because unsure".
5. **Position against Alexa+ and Gemini Spark with a hands-on test.** Run 5 tasks (shop price, salon slot, AC repair quote, hold on a support line, restaurant with no online booking) on Alexa+ India and Spark and record what each cannot do. Their gap, if confirmed, is calling phone-only Indian vendors; copy only their "asks before spending/sending" clarity. Measure: tasks completed vs Friday, user-stated reason to use Friday in pilot interviews.
6. **Browser agents: track recovery, not model score.** Add a nightly replay of each connector (Zomato, Swiggy, Zepto, etc.) on fakes and, with approval, supervised real runs, tagging failures as selector drift, login expiry, modal, irreversible. First step: define the failure taxonomy and a "hand over to the user" rule. Measure: recovery rate per failure type, steps per task, handover rate, zero payment/OTP touches.
7. **Benchmark turn-taking against off-the-shelf.** Run LiveKit's multilingual detector (lists Hindi) and Pipecat Smart Turn v3 against Friday's own end-of-turn on the same recorded calls. Measure: premature cut-offs, long pauses, barge-in recovery. Adopt only if clearly better; otherwise keep ours.

## (d) Ignore, and why

- **AP2, ACP, UCP, x402, Ant AMP**: card/crypto standards; Friday's rail is UPI and its rule is no payments. Watch only NPCI UAP and Pine Labs P3P.
- **Voice cloning, celebrity voices**: not needed; adds IT Rules and consent risk for no user gain.
- **On-device models and hardware**: already assessed (ghost.ai in COMPETITORS); not a pilot need.
- **WhatsApp Plus, Meta Business Agent per-token billing**: consumer cosmetics and vendor-side cost; no Friday impact found.
- **Another memory framework swap (Mem0/Zep/Letta)**: scores are self-reported; at pilot scale our tables suffice (TECH_BETS). Use Mem0's eval harness for tests only.
- **Business-side voice bots as "competitors" (Ringg, CallMissed, Wati)**: they are the counterparties Friday will meet, not rivals.
- **Wishup, Yana AI**: old, no AI-calling evidence.
